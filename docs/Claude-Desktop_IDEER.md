# Idéer til senere

Ting, Jon har nævnt, og som er værd at huske. Skrevet af Claude-Desktop.

## Hordetesten som eget spil eller game mode (Jon 24/10)
- **Udgangspunkt:** hordetesten (`web/Claude-Desktop_bam_hordetest_v1`) med 1.000-40.000 zombier, minigun og granat. Jon synes, den kunne blive et spil i sig selv eller en game mode i BAM.
- **Det, der allerede virker:**
  - de mange zombier kører flydende på Jons pc (48 billeder/s med 40.000);
  - zombierne har forskellige hastigheder, og "løberne" virker godt;
  - de fylder plads og pakker sig rundt om spilleren.
- **Mulige næste skridt:**
  - bølger, der bliver større og større;
  - point og en rekordliste;
  - våben, der kan opgraderes;
  - forsvarsværker: hegn, miniguns, miner;
  - zombier, der angriber, og at spilleren kan dø;
  - et rigtigt landskab med forhindringer.
